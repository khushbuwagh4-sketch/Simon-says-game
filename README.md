# 🎮 Simon Says Game

An interactive Simon Says memory game built using HTML, CSS, and JavaScript.

## 🚀 About the Project

This project is a browser-based memory game where the player needs to remember and repeat the sequence of colors generated by the game.

The project was built to practice JavaScript fundamentals and create an interactive web application using DOM manipulation and event handling.

## ✨ Features

- 🎮 Interactive gameplay
- 🔢 Progressive levels
- 🎨 Dynamic color sequence
- 🖱️ User interaction through button clicks
- 🔄 Game restart functionality
- 📱 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🧠 JavaScript Concepts Practiced

- DOM Manipulation
- Event Handling
- Arrays
- Functions
- Conditional Statements
- Random Number Generation
- Game Logic

## 🎯 Learning Objective

The main goal of this project was to strengthen JavaScript fundamentals by building a real-world interactive browser game.
